# Engenharia de Software II — Atividades

Repositório destinado ao armazenamento e à organização das atividades práticas desenvolvidas na disciplina de **Engenharia de Software II**.

## 📚 Sobre o repositório

Este repositório reúne exercícios e arquivos utilizados durante as atividades da disciplina, incluindo códigos-fonte em linguagem C, executáveis gerados durante a compilação e materiais de apoio.

## 🗂️ Conteúdo

Entre os arquivos presentes no repositório, estão:

- `AtividadeENGSOFT07.c` — código-fonte de uma atividade da disciplina.
- `Parte2_Ativ7 - Fatorial-Testes.c` — exercício relacionado ao cálculo de fatorial e testes.
- `Parte3_ativ_eh_primo.c` — exercício de verificação de números primos.
- `Parte4_Ativ7_Celsius_for_fahrenheit...` — exercício de conversão de temperatura de Celsius para Fahrenheit.
- `Teste_baskhara.c` — código relacionado à fórmula de Bhaskara.
- `Aula 6.docx` — material de apoio da aula.
- Arquivos `.exe` — executáveis gerados para testar alguns dos programas.

> **Observação:** os nomes acima foram organizados com base nos arquivos presentes no repositório. Consulte cada código-fonte para verificar o enunciado e os detalhes de implementação.

## 🛠️ Tecnologias e ferramentas

- **Linguagem C**
- Compilador C compatível, como GCC
- Git e GitHub para versionamento e organização dos arquivos

## ▶️ Como executar os programas

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd NOME_DO_REPOSITORIO
   ```

3. Compile um arquivo `.c` usando o GCC. Por exemplo:

   ```bash
   gcc "AtividadeENGSOFT07.c" -o AtividadeENGSOFT07
   ```

4. Execute o programa compilado:

   **Windows (Prompt de Comando):**
   ```bash
   AtividadeENGSOFT07.exe
   ```

   **Linux:**
   ```bash
   ./AtividadeENGSOFT07
   ```

Repita o processo substituindo o nome do arquivo pelo exercício desejado. Caso o código utilize recursos específicos do ambiente, podem ser necessários ajustes para compilá-lo em outro sistema operacional.
